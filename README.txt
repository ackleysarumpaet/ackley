CARA MENJALANKAN:
1. Extract ZIP.
2. Buka folder MOTOCARE_V2 di VS Code.
3. Install extension Live Server.
4. Klik kanan index.html -> Open with Live Server.
5. Coba booking dari booking.html.
6. Login sebagai Boss atau Mekanik.
